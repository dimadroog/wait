# Операторский пресет FCEUX (эфир / Live)

Полный файл [`fceux.cfg`](fceux.cfg) — настройки показа для эфира: звук, громкость, шейдеры (`winspecial` / `vmspecial`), палитра и прочие ключи FCEUX.

## Как править

1. Настройте FCEUX (Config → …) на том экземпляре, которым пользуетесь для эфира.
2. Скопируйте получившийся `fceux.cfg` сюда (замените этот файл целиком).
3. При следующем `run_inference --live` или GUI `play_inference_fm2` (без `--noicon`) пресет **целиком** копируется поверх `fceux/portable/fceux.cfg`.

Train / Pool (headless) пресет не применяют и по-прежнему глушат звук в служебном cfg.

Исходный посев: копия с рабочей машины оператора (`fceux-2.6.5-win64`); рантайм путь `D:\games\…` в коде не используется.
